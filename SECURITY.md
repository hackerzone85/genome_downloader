# Security Policy

## Supported Versions
We currently support and provide security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within this tool, please do not open a public issue. Instead, follow these steps:
1. **Email:** Send a report to [mahendra.gbu@gmail.com] (or use GitHub's [Private Vulnerability Reporting](https://docs.github.com)).
2. **Details:** Include a description of the issue and steps to reproduce the vulnerability.
3. **Response:** You can expect an initial response within 48 hours.

We appreciate your help in keeping this downloader secure for the genomics community.
